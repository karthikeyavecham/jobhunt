Import a job posting

Paste a URL and it will be fetched, or paste the posting text directly. Either way an LLM parses it into the same pipeline as every other posting — scored, filterable, and able to generate a CV.

Their terms forbid automated fetching, and they block it in practice. Opening the posting and copying the text works exactly as well — and avoids putting your LinkedIn account at risk, which is the account you actually need right now.

What happens next

  • The posting is parsed into title, company, location and description.
  • It is scored immediately rather than waiting for the next 3-hour cycle.
  • It skips the region filter — importing by hand is taken as intent.
  • Re-importing the same URL updates the existing entry instead of duplicating it.
