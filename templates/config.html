Language model

The local model is tried first. If it cannot be reached after the configured number of attempts — the usual cause is the Mac being asleep — the app falls back to Claude so the schedule still produces scores.
Scoring throughput
LM Studio batches concurrent requests, so parallel scoring is a real gain rather than just queueing. Measured on qwen3.8-27b, scoring the same postings:
In parallelThroughputPer request
12.2 jobs/min27s
23.9 jobs/min31s
45.1 jobs/min37s
86.1 jobs/min53s
3 or 4 is the sweet spot. The big win is going above 1; past 4 throughput flattens while each request keeps slowing down, and the Mac is busier the whole time. Raise it to drain a backlog, lower it when you need the machine.
